# 03-知识 工作区规范

## 用途

沉淀已经处理过的知识卡片、主题笔记、学科笔记、概念页，以及**论文阅读笔记**。

## 允许

- 知识卡片
- 主题笔记
- 学科笔记
- 概念解释
- 论文阅读笔记（归入 `论文/<研究方向>/`）

## 禁止

- 原始网页全文
- 项目执行文件
- 发布成品

## 目录结构

按「论文 / 非论文」分两大类：

- `论文/<研究方向>/` — 论文阅读笔记，按研究方向分（见下方概览）
- `工程实践/` — 实验记录、开发文档、调试结果（**非论文**，定义见 `工程实践/WORKSPACE.md`）
- `阅读日报/` — 每日阅读总结（非论文类，见文末说明）

## 命名

使用 `YYYYMMDD_主题.md`。论文统一放在 `论文/` 下，按研究方向分一层子目录；
非论文内容放在 `工程实践/`。系列编号可保留在文件名中，不再建立更深的目录层级。

## 论文分类流程（模型）

对新加入的论文，按以下三步归类：

### 1. 粗匹配（读本概览）
根据本概览的「一句话定义 + 关键信号」，选出 **1~N 个候选类**（可多选，宁多勿漏）。

### 2. 精准匹配（读候选类的 `WORKSPACE.md`）
依次阅读候选类的 `WORKSPACE.md` 精细定义，重点看其中的 **「边界与歧义（vs 兄弟类的判别规则）」**，
按判别问题决定最匹配的一类，将论文移入 `论文/<最匹配类>/`。

### 3. 无匹配 → 生成待审核新类
若粗匹配**没有合适类**：
1. 新建 `论文/<新类名>/` 目录，写入 `WORKSPACE.md`（含该类的精细定义）。
2. 该 `WORKSPACE.md` 的 frontmatter 标 `status: 待审核`。
3. 把该论文**暂放入**新类目录。
4. 在 `论文/_待审核分类.md` 登记（新类名 + 定义摘要 + 提出日期 + 状态）。
5. **交给用户审核**：用户确认后将该 `WORKSPACE.md` 的 `status` 改为 `active`，即正式生效；
   若用户决定合并/废弃，则移动论文并删除该临时类。

> 原则：归类是**先粗后精、可回溯**的过程；不确定时优先进入候选类，再由精细定义裁决，
> 而非凭印象一次性判定。

---

## 待审核分类

待审核的新类统一登记在 `论文/_待审核分类.md`（带 9 字段 frontmatter，初始为空）。
审核方式：用户将对应类的 `WORKSPACE.md` 中 `status` 由 `待审核` 改为 `active` 即生效。
Agent 在粗匹配时应**同时扫描**该文件，避免重复提议已待审核的同类。

---

## 阅读日报（非论文类）

`03-知识/阅读日报/` 存放**每日阅读总结**（如 `20260721_昨日paper阅读报告.md`），
是对当日所读论文的跨文章摘要与观察，**不参与**上述论文研究方向归类。
论文笔记本身仍归 `论文/<研究方向>/`，日报仅做汇总与回溯。

## Frontmatter

`workspace` 必须为 `03-知识`，`type` 使用 `note` 或 `card`。
论文与笔记须满足 9 字段规范（title / type / topic / workspace / created / modified / tags / source / status）。

使用 `workspace-knowledge`。
