# 03-知识 工作区规范

## 用途

沉淀已处理的知识：论文笔记、学习笔记、灵感想法。不按研究方向建目录。

## 允许

- 论文笔记（阅读后的论文卡片/总结）
- 学习笔记（课程、书籍、方法、工具心得）
- 灵感想法（`some idea/`，未成型的点子与随想）

## 禁止

- 原始网页全文
- 项目执行文件
- 发布成品

## 命名

使用 `YYYYMMDD_主题.md`。主题目录只保留一层：`论文笔记/`、`学习笔记/`、`some idea/`。系列编号可以保留在文件名中，但不要再建立二级主题目录。

## Frontmatter

`workspace` 必须为 `03-知识`，`type` 使用 `note` 或 `card`。

## 子 Skill

使用 `workspace-knowledge`。
