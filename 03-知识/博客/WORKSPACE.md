# 博客 / 长文阅读（非论文）

> 本文件夹存放**网页博客、技术长文、Wiki、课程笔记**等阅读内容，**不是论文**。
> 与 `论文/<研究方向>/` 的 arXiv 论文阅读笔记区分：这里放的是作者个人博客、技术长文、课程/科普笔记。

## 纳入标准
- 个人 / 机构博客技术长文（如 Lilian Weng、Shilong Liu 博客）
- 课程 / 讲座笔记（如大学具身智能导论）
- 主题 Wiki / 知识库首页快照（如 RL-for-LLMs Wiki）

## 不纳入
- arXiv 论文阅读笔记 → `论文/<对应研究方向>/`
- 实验 / 开发记录 → `../工程实践/`
- 每日阅读汇总 → `../阅读日报/`

## 命名
沿用 `YYYYMMDD_主题.md`，frontmatter 同 03-知识 规范（`workspace: "03-知识"`）。
