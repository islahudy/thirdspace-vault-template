# ThirdSpace 控制面契约统一 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Schema、工作区协议、Skill 路由、LifeOS 初始数据和审计器统一到一份可机器验证的控制面契约。

**Architecture:** `.thirdspace/schema/` 保持唯一机器事实源，`WORKSPACE.md` 和 Skill 作为人类/代理执行说明。`thirdspace-vault.mjs` 使用无依赖的定向 YAML 解析器读取枚举和工作区块，以审计阻止跨文件漂移。

**Tech Stack:** Node.js ESM、`node:test`、Shell、YAML/Markdown/JSON。

**Spec:** `00-系统/规范/11_控制面契约统一设计.md`

## Global Constraints

- 不新增外部运行时依赖。
- 不迁移、删除或重写用户知识内容。
- `.thirdspace/schema/` 是唯一 Schema 事实源。
- 全局 Frontmatter 必填 9 字段保持不变，领域字段使用条件扩展。
- 所有生产修复都先观察对应回归测试失败。
- 用户已明确同意在当前 `main` 分支直接修复。
