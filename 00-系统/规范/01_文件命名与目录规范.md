# 文件命名与目录规范

## 顶层原则

顶层目录表达工作状态，不表达所有分类维度。

## 默认命名

新 Markdown 文件默认使用：

```text
YYYYMMDD_主题.md
```

## 项目命名

项目目录使用：

```text
YYYYMMDDHHMM_项目名/
```

项目目录内允许使用短文件名，例如 `brief.md`、`plan.md`、`assets.md`、`review.md`。

## 层级限制

- 普通工作区最多两层。
- 项目工作区最多三层。
- 主题、来源、状态写入 Frontmatter，不继续加深目录。
